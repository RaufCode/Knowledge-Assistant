# Technical Departments & Tech Stack

**Effective date:** 1 January 2026
**Last reviewed:** September 2026
**Owner:** Office of the CTO

This document lists the primary technologies used across Acme Technologies' four technical departments. Individual client projects may use additional tools, but the following are the standard, supported stacks.

## Software Engineering

- **Backend:** Java (Spring Boot), C# (.NET), Node.js (NestJS/Express)
- **Frontend:** React, Angular, TypeScript, Next.js
- **Mobile:** Flutter, Kotlin (Android), Swift (iOS)
- **Databases:** PostgreSQL, MySQL, MongoDB
- **API & messaging:** REST, GraphQL, RabbitMQ

## Data & AI

- **Languages:** Python, SQL
- **ML/AI:** PyTorch, TensorFlow, scikit-learn, Hugging Face Transformers
- **Data processing:** pandas, Apache Spark, dbt
- **Pipelines & warehousing:** Apache Airflow, Snowflake, BigQuery
- **LLM/RAG tooling:** LangChain, vector databases (Chroma, pgvector)

## Cloud & DevOps

- **Cloud providers:** AWS (primary), Microsoft Azure
- **Containers & orchestration:** Docker, Kubernetes
- **Infrastructure as code:** Terraform
- **CI/CD:** GitHub Actions, Jenkins, Argo CD
- **Monitoring & logging:** Prometheus, Grafana, the ELK stack

## Quality Assurance (QA)

- **Web/UI automation:** Selenium, Cypress, Playwright
- **Unit/integration:** JUnit, xUnit, Jest
- **API testing:** Postman, REST Assured
- **Performance testing:** k6, JMeter
- **Test management:** TestRail, Xray for Jira

## Cross-cutting tools (all technical departments)

- **Version control:** Git, hosted on GitHub
- **Project tracking:** Jira and Confluence
- **Communication:** Microsoft Teams and Slack
- **Design handoff:** Figma
