# Acme Technologies Ltd. — Policy Corpus (Synthetic)

This folder is the **knowledge source** for the Internal Knowledge Assistant PoC.

These documents describe a **fictional company, Acme Technologies Ltd.** They were written for demo purposes and contain **no real employee data**. When (and if) the real AmaliTech handbook is approved for use, these files can be swapped out and the same ingestion pipeline will index them unchanged.

**Corpus rules (keep these when adding docs):**
- One policy per file; filename = policy name.
- Start each file with a title (`#`) and an **Effective date** line.
- Use clear section headings — they improve chunking and citations.
- No real PII, no real salary tables, no scanned PDFs.

**Files:**
1. `01-company-overview.md` — about, employee count, departments & roles, core values
2. `02-technical-departments-and-tech-stack.md` — tech stacks per technical department

4. `04-leave-policy.md` — sick leave, annual leave, carryover
5. `05-compensation-and-payroll-policy.md` — salary raises, pay dates, salary advance, bonuses
6. `06-onboarding-policy.md` — onboarding process
7. `07-code-of-conduct-and-workplace-behaviour.md` — conduct, handling colleague conflict
8. `08-employee-engagement-and-activities.md` — employee activities
9. `09-security-and-compliance-policy.md` — reporting security/compliance concerns
